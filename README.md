# Contributing to the Neverwinter Vault

This repository tracks issues and feature requests for the **current** Neverwinter Vault running at [neverwintervault.org](https://neverwintervault.org).

## How to Help

### Report Issues

If you've found a bug or have a feature request for the current Vault, please open a GitHub issue. Include as much detail as you can — steps to reproduce, screenshots, or example links are all helpful.

### New Vault Platform

We are actively working on a rebuild of the Vault on a modern platform. If you have suggestions, feature requests, or want to contribute to the new Vault, please visit:

👉 **https://github.com/vault-lexicon/vault**

## Code of Conduct

Be respectful. This is a volunteer community project — treat other contributors the way you'd want to be treated.
